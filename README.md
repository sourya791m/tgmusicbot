# 🎵 Telegram Music Bot

A fast and powerful music bot for Telegram that allows you to play songs from YouTube, Spotify, SoundCloud, and more in voice chats.

## ✨ Features

- Play music from YouTube, Spotify, SoundCloud, etc.
- High quality audio streaming
- Queue system
- Skip, pause, resume, stop
- Volume control
- Now playing information
- Loop & Shuffle
- Search songs
- Clean and user-friendly interface
- Works in groups and private chats

## 📋 Requirements

- Python 3.10 or higher
- FFmpeg
- Telegram Bot Token (from [@BotFather](https://t.me/BotFather))
- API ID & API Hash (from [my.telegram.org](https://my.telegram.org))
